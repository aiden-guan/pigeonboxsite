AI SETUP

Choose your model.

Use a local model, Chrome’s built-in Gemini Nano where available, Ollama, or your own provider key. Some options need a network connection.

YOUR DATA

Stored in this browser.

Your inbox index, drafts, rules, and settings stay in local browser storage. Ask Inbox links answers to source threads and shows when coverage is limited.

Tracking is optional.

Use no tracker, or connect one you host. Tracking stores message details and open/click activity, not email bodies. Inbox features work without it.

Set up from source

local setup● ● ●
$ git clone https://github.com/aiden-guan/pigeonbox.git
$ cd pigeonbox
$ npm run setup -- --open

The repository includes setup, verification, and self-hosting documentation.
