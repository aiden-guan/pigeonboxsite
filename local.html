02 — ModelsSettings → AI

Pick your model.

PigeonBox never switches providers on its own.

  • On-deviceSmall open models on WebGPU (Gemma, Qwen, LFM2, SmolLM2). Weights download from Hugging Face once.
  • Chrome built-inGemini Nano, on Chrome 138+ desktop.
  • OllamaAny model running on your machine.
  • Your keyOpenAI or compatible. That provider sees what you send it.
  • AI offSorting still works.
03 — Install~5 minutes

Three ways in.

Chrome, Edge or Brave 116+. Node 20+ to build.

A · Ask your coding agent
Install PigeonBox for me by following https://raw.githubusercontent.com/aiden-guan/pigeonbox/main/INSTALL.md
B · One command
$ git clone https://github.com/aiden-guan/pigeonbox.git
$ cd pigeonbox
$ npm run setup -- --open
C · Download a releaseNo Node
# unzip from
github.com/aiden-guan/pigeonbox/releases
  1. 1Open chrome://extensions, turn on Developer mode.
  2. 2Load unpacked → apps/extension/dist.
  3. 3In Gmail, choose On this computer.
