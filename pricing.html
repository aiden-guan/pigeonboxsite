FAQ

Short answers.

01Is Local a trial?

No. It’s the complete Local feature set, free and open source, with no time limit. Cloud is a separate hosted mode.

02Can I buy Cloud?

Not yet. It’s a private beta with test-mode billing.

03Does PigeonBox use the Gmail API?

Local doesn’t request Gmail API OAuth. Cloud uses Google APIs only after you connect your account.

04Does Cloud store my mail?

Not the bodies, by default. It keeps metadata and encrypted summaries so it can work while Gmail is closed. Opt-in Fast Recall adds encrypted excerpts.

05Does Local send mail to PigeonBox?

No. If you choose an external AI provider, it receives the text you send it; an optional tracker you host receives tracking metadata.

06Will it send email for me?

No. Local drafts stay in Gmail for you to review and send. Any Cloud action that sends mail requires your approval.

07Is an open a read receipt?

No. It’s a signal. Privacy proxies can hide or fake it.

08Do I need a powerful computer?

No. Sorting works with AI off. Ollama or your own key are options too.

09What if I delete my Cloud account?

Your Cloud data is designed to be deleted with it. Browser data stays until you clear it.
